{report}

Follow these steps:

1. Read the report and identify the affected URL.

2. Retrieve the Puppeteer reproduction script (a mjs file, typically titled
   `Reproduction script generated by autowebcompat bot`) and download it
   to exactly this path: {script_path}.

3. If there is no reproduction script, set `script_path` to null. Do not
   substitute a testcase or write a script yourself.

4. Determine the platforms the issue affects. If the bug's `cf_user_story`
   is not empty and has a `platform` field, copy its values as they are, e.g.
   `windows,mac,linux,android` → `["windows", "mac", "linux", "android"]`.
   If it lists only some desktop OSes, list all three unless the report or
   comments say the issue does not reproduce on the others. Add `android` if
   the report or comments show the issue on Android.

   Otherwise, work it out from the report:

   - Is it described as affecting only Firefox for iOS? Then use `["ios"]`,
     as it is unlikely to affect other platforms.
   - Does it affect desktop and Android, or only one?
   - If it affects desktop, is there evidence it is OS-specific? An issue is
     only OS-specific if the report states it did not reproduce elsewhere —
     reporters often test just one OS. Otherwise list all three desktop OSes.
   - If it affects every platform, list ["windows", "mac", "linux", "android"].

5. Submit your findings via `submit_result` (see "Reporting your result").
